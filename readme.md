# Title
How real is home court advantage in the NBA?

# Question
Is home court advantage real in the NBA, and by how much? (Regular season, 2000-01 to 2014-15)

# Data
The data comes from a Kaggle dataset: [NBA Dataset: Box Scores and Stats (1947 - Today)](https://www.kaggle.com/datasets/eoinamoore/historical-nba-data-and-player-box-scores) by [Eoin A Moore](https://www.kaggle.com/eoinamoore). While the dataset covers from 1947 to present day, I'll only be using the data from the 2000-01 to 2014-15 regular season.
